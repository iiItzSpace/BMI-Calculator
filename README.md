# 🧮 BMI Calculator

Body Mass Index (BMI) calculator for adults, built as my first functional mini web project.

**Note:** The user interface is in Spanish, as the web is intended for a Spanish-speaking audience.

## 💡 What it does ?

Lets you enter weight (kg) and height (m) to calculate BMI and display the corresponding category (underweight, normal weight, overweight, obesity class I/II/III), based on the World Health Organization (WHO) standard classification.

## 🛠️ Tech stack

- HTML5
- CSS3
- JavaScript (vanilla, no frameworks)
- Webpack (based on HTML5 Boilerplate)

## 📐 Formula and source

BMI = weight (kg) / height (m)²

Classification ranges are based on the WHO international standard for adults.

## 🚀 Running it locally
To run this project locally, make sure you have **Node.js** installed on your computer. Then, run the following commands in your terminal:
```bash
npm install
npm start
```

This automatically opens the project in your browser with live reload.
